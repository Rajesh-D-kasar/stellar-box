# Contributing to Stellar Box

First off, thank you for considering contributing to **Stellar Box**! It's people like you that make the Stellar ecosystem such a great community.

## 🧠 What is this repository?
Stellar Box is a lightweight, educational dApp toolkit built with React and Vite. It is designed to demonstrate how to connect to the Freighter wallet, interact with the Stellar Horizon Testnet, and submit XLM payment transactions.

## 🛠️ How to contribute

### 1. Reporting Bugs
If you find a bug, please use our **Bug Report** issue template. Include as much detail as possible, such as:
- Browser and OS version
- Freighter Wallet version
- Steps to reproduce
- Relevant screenshots or console errors

### 2. Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Use the **Feature Request** issue template to outline:
- The problem your feature solves
- A proposed solution or architecture

### 3. Submitting Pull Requests
1. Fork the repository and create your branch from `main`.
2. Run `npm install` to install dependencies.
3. Make your changes in a modular, clean fashion.
4. If you've added code that should be tested, add tests!
5. Ensure your code passes our linting: `npm run lint`.
6. Issue a Pull Request with a clear title and description referencing any open issues.

## 💻 Development Setup
Ensure you have Node.js (v18+) installed.

```bash
git clone https://github.com/Rajesh-D-kasar/stellar-box.git
cd stellar-box
npm install
npm run dev
```

You will need the [Freighter Wallet](https://www.freighter.app/) extension installed and switched to the **Testnet** network to fully interact with the dApp locally.

## 🤝 Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. Be respectful and constructive!
